# 车辆跟随线路颜色

让车辆自动使用所属线路的颜色，方便区分交叉运行的不同线路。沿用系统分配或你手动选择的线路颜色，同一种货物的多条线路也可以保持各自配色。

安装方式见[项目说明](../README.md#安装)。

## 使用

1. 在存档的模组列表中启用“车辆跟随线路颜色”。
2. 首次启用时，为已有线路车辆补同步一次颜色。
3. 在线路中购车、从车库派车、从其他线路调入车辆或替换车辆成功后，只同步本次操作涉及的车辆。
4. 主动修改线路颜色后，同步这条线路的所有车辆。

适用于当前玩家线路中的公交、货车、有轨电车、火车、轮船、飞机和直升机，包括火车编组内支持涂色的车头和车厢。只改变车型允许涂色的部分；原有图案和固定涂装可能影响实际观感。不支持涂色的车型、未分配线路的车辆保持原样。空车也跟随所属线路颜色。

平时不反复检查全车队。单独给车辆改色后会保留你的配色，普通读档也不会重新覆盖；该车之后换线、替换，或你修改所属线路颜色时，才重新同步。车辆较多时逐批处理。车辆名称保持原样。

自动同步针对原版界面的车辆和线路操作；其他模组在后台直接调车或改色时，不保证触发。停用后保留最后一次同步的颜色。避免同时启用其他自动修改车辆颜色的模组。更新后请重启游戏并重新载入存档。
