# 常见立交桥合集

在“道路 → 立交桥”独立分类中添加六类小型高速立交。主线可选单向两车道或三车道，共 12 种基础组合；固定使用小尺寸和混凝土桥。与使用的原生高速公路一样，从 1940 年开放，适用于右侧通行。

| 类型 | 可选功能 |
| --- | --- |
| 苜蓿叶立交 | 共用弧段为游戏自带的一条双向道路，每向一条车道；四片叶子可分别关闭，右转保留 |
| 菱形立交 | 主路跨接双向道路，四条进出匝道可分别关闭；横向道路保留高架接头 |
| 喇叭形立交 | 三路相接，含一条环形匝道 |
| 定向 T 形立交 | 三路相接，使用分层定向匝道，无环形叶片 |
| 涡轮形／旋涡立交 | 四路相接，左转匝道绕中心展开，各转向独立 |
| 四层全互通枢纽 | 四路相接，两层主线与两层左转匝道，支持全部转向 |

设置中的“车道”选择主线单向 2 或 3 车道。尺寸、道路类型和桥型均已固定，不提供其他规格。

苜蓿叶与菱形使用同一排 **1、2、3、4 编号按钮**，可分别开关，对应菜单预览图编号，默认全开，旋转时一起转动。关闭叶片后，该处自动改成平顺的右转匝道，不再绕原叶片轮廓行驶；关闭菱形匝道会取消对应出入口。

## 安装与使用

安装方法见[项目说明](../README.md#安装)，选择目录 `interchange_pack`。

1. 在存档模组列表启用“常见立交桥合集”。
2. 打开“道路 → 立交桥”，选择所需立交类型。该分类位于官方“道路构造”之后。
3. 调整参数，用游戏原生旋转、升降操作放置，再将各方向端点接入路网。

菱形的横向端点保持高架高度，使用原生双向两车道道路；并道口采用原生三车道短接头，中央主线仍按车道选项设置。喇叭形和定向 T 的支路固定为单向两车道，东西主线可选两车道或三车道。其他模板的外接端点均位于建造基准高度。三路立交及多层枢纽会略微下沉主线以缩短引道。建成后可使用普通道路工具编辑，模板参数用于放置前设置。

## 使用限制

两车道版的中心线范围：苜蓿叶约 280×280 米，菱形约 180×160 米，喇叭形约 278×215 米，定向 T 形约 270×156 米，涡轮形约 432×432 米，四层枢纽约 430×430 米。三车道需要更宽的接头和弯道，占地略有增加。这些数值不包含路面边缘。

紧凑引道较陡，适合相对平整的空地。陡峭地形、桥墩与既有设施冲突，以游戏施工检查为准。

菱形匝道与横向道路为平交连接，苜蓿叶主线上仍有汇入、驶出的交织。共用弧段使用一条原生双向乡村公路，两端接单向高速匝道。节点允许的转向由游戏生成；各模板不设专用掉头匝道，车辆仍可能利用多条匝道绕回。

菜单图片为透明背景的写实路型示意，实际车道和路面效果以放置预览为准。
