# 工厂地块规整

按指定方向整理作物农场、牲畜养殖场、棉花农场、橡胶农场和伐木场的地块，并开放新建产业的完整成长上限。

安装方式见[项目说明](../README.md#安装)。

## 整理地块

1. 启用模组并加载存档，打开支持的产业窗口。
2. 选择“前、后、左、右”中的至少一个方向，可多选。
3. 点击“整理地块”。产业扩建后或需要更换方向时，可再次整理。

方向随工厂旋转，左右以从厂内面向大门为准。选择“前”会把地块排到门前道路对面；左右和后方位于厂房一侧，门前道路留空。

地块沿与厂区相连的陆地紧凑排列，不跨水面跳到其他岛屿。当前地块放不下或游戏拒绝施工时，会保留原布局并显示原因。整理保留地块数量、生产能力、工厂位置和名称。

整理时若没有足够空间预留新地块，后续扩建会受限；腾出空间后可再次整理。

布局随存档保存。已整理的存档应继续启用本模组；移除后，产业再次更新会恢复原版布局。

## 产业成长上限

创建新地图前启用模组，新生成的原版可扩建产业会使用全部预设地块作为成长上限。产业仍按原版条件逐步成长，地形和障碍物仍可能限制实际扩建；存档中已有产业的上限不会自动改写。

已包含“产业最大成长上限”的功能，无需同时启用该独立模组。当前版本的游戏内整理效果仍待确认。
