# 工厂地块规整

Transport Fever 3 模组，支持原版作物农场、牲畜养殖场、棉花农场、橡胶农场和伐木场的地块整理，并包含可扩建产业的最大成长上限功能。

## 产业成长上限

已合并 `industry_max_potential` 的功能，只需启用“工厂地块规整”，独立的“产业最大成长上限”模组可以停用。创建新地图之前启用本模组，地图生成的产业就会使用完整成长上限，无需先点击整理。

覆盖原版14类可扩建产业：黏土坑、煤矿、棉花农场、作物农场、渔场、伐木场、铁矿、牲畜养殖场、海上钻井平台、油井、采石场、橡胶农场、采砂船和沙坑。上限为该产业全部预设扩建地块的数量，例如作物农场20块、煤矿8块、橡胶农场23块。

产业仍按原版条件逐步成长，地形和障碍物仍可能阻止实际扩建。当前地块数量、生产配方、库存和生产加成保持原版行为。此功能不主动改写存档里已有产业的上限；另外18类加工产业沿用原版规则。

## 使用

启用模组并读档后，点开农场的产业窗口，点选“前、后、左、右”，选择至少一个方向，再点“整理地块”。四个方向按钮可独立选择和取消，支持多选。

地块在选中区域内优先补齐近处的行列和凹口，再向外扩展；分配数量按整体轮廓安排。剩余地块能补成完整矩形时，优先补齐。可以自由取消全部方向，此时“整理地块”按钮暂不可用。

方向以厂门横向道路为分界，并随工厂整体旋转；左右以从厂内面向大门向外看为准。左右和后方地块留在道路靠厂房的一侧；只有选择“前”才会排到道路另一侧。“前”和“后”分别覆盖门前横路以外、厂尾以外的区域，都可向两侧展开。门前横向道路留空，路对面地块连续排列。贴厂的第一排按实际厂界对齐，内侧行列按厂体尺寸分为矩形，外圈以80米格子继续延伸。地块之间不额外留间隙或添加田间小路；原版作物边缘和树篱仍保留。

前方第一排从厂门道路边开始排列，后续地块向外连续扩展。

选位从贴近厂区的陆地开始，沿相邻格子逐块向外排列，并检查到厂区的陆地连接，不能越过水面跳到其它岛上。一侧不足时可分配到其它已选方向。当前地块必须全部放在这片连通陆地内，否则保留当前布局并说明原因。

未来地块也只预留在同一连通区域，没有可用位置的空槽暂不参与扩建；重新整理可以重算可用位置。地块总数及原版产能计算所用的槽位总数保持不变。选位结果随存档保存，最终施工仍使用原版检查。

可以多次整理。产业升级增加地块后，再点一次，就会按当前地块数量重新分配；也可以换一个方向再整理。连接道路本身不是禁用条件。整理使用游戏原生的已有建筑更新流程，施工是否允许由原版检查决定；地块只分配到选中的方向，失败时显示游戏返回的原因。

整理保留原有地块模块、数量、工厂位置和名称，沿用原版生产计算。布局选择随存档保存。已整理的存档应继续启用此模组；移除模组后，产业再次更新会使用原版布局。

## 开发与验证

`content/tidy_fields/generated` 保存当前游戏版本的原版农场模型布局；游戏更新农场资源后，可用 `tools/import_farms.py` 从安装目录重新导入。地块绘制和生产计算继续使用游戏自带的公共脚本。

Lua模拟测试覆盖产业生成上限、布局、道路避让、原版生产计算、地块数量保留、方向选择和重复整理。模拟测试不代替游戏内验证；当前版本的实际画面尚需确认。
