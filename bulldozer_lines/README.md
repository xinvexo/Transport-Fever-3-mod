# 拆除时查看线路

打开普通推土机时，自动显示地图线路和左侧的紧凑线路面板，方便对照线路拆除站点。

- 面板包含搜索框、运输方式筛选和带边框的线路清单，不显示载具列表和停靠站详情。
- 公路、电车、铁路、船舶、飞机图标可以组合勾选；全部取消表示不限运输方式。
- 眼睛按钮单独控制“只显示可视范围”，会随镜头移动更新。
- 勾选一条或多条线路后，地图只显示勾选的线路，其余线路完全隐藏。
- 类型与可视范围筛选同时限制清单和地图显示。没有勾选线路时显示筛选结果；已勾选的线路被筛除后，不会自动显示其他线路。
- 每条线路右侧的定位按钮可以将镜头移到该线路，继续使用推土机。
- 顶部左侧复选框用于全选当前列表，再次点击取消全部勾选；筛选条件保留。
- 搜索框用于查找清单里的线路，不会清除已勾选线路。
- 退出推土机时清单自动关闭；点击清单的关闭按钮也会退出推土机。清单可拖动。
- 按 B 或点击普通推土机按钮后，房屋持续按住宅绿色、商业蓝色、工业黄色显示，退出推土机后恢复；若改过按键，以当前推土机快捷键为准。

安装方式见[项目说明](../README.md#安装)，安装后在存档模组列表中启用“拆除时查看线路”。

地图点击仍用于原版拆除操作；清单用于查看、勾选和定位，不提供线路编辑、删除或载具管理。正常打开线路管理器时保留原版完整界面。此功能针对普通推土机，不用于车站模块删除工具。

手动开启其他数据图层时，房屋颜色以该图层为准；关闭后恢复推土机配色。
