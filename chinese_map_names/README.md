# 预设地图中文名称

从豪华版等预设地图创建新游戏时，将地图内已有名称换成中文。城市和街道使用游戏自带的中国名称库，人物使用汉字姓名；后续新增对象继续使用中文名称。

覆盖城市、街道、人物、产业、车站（包括港口和机场）、车库、维护楼、仓库、总部，以及独立地标、信号设施等建筑的名称。地图中已有的原版编号线路名、车辆名也会转换为中文。

原有地名会换成中国名称，例如换为“北京”“上海”，并非原地名的中文音译。地图地形、城市位置和产业布局不变。

安装方式见[项目说明](../README.md#安装)。选择预设地图后，在开始新游戏前启用“预设地图中文名称”。进入地图后让游戏运行片刻，完成已有名称的替换。

更新模组后请重启游戏。已启动但尚未完成的开局改名任务，可通过读取该存档继续处理，无需重新生成地图。

城市和工厂等设施优先改名，再处理街道和居民。使用过本模组的旧存档在本次更新后加载时，会一次性补齐遗漏的外文产业名称，保留已改好的中文城市名。

仅在新开局、恢复未完成任务和上述一次性补齐时处理名称；任务完成后停止扫描和改名。

请使用简体中文游戏界面，产业类型和车站等设施后缀沿用游戏的中文翻译。后续继续这个存档时保持模组启用，否则新名称可能恢复为地图原来的命名地区。

没有独立名称的车站等对象跟随所属建筑或名称来源变化。无法安全改写的显示名称会保留原样并记入游戏日志。

本模组适用于新开局。中途加入已有存档不会批量重命名已有对象，但会改变之后的名称生成方式；不需要中文命名的地图请勿启用。在地图编辑器中不生效。

保留玩家昵称、公司名以及非默认的自定义线路、车辆名称，不修改地图选择菜单中的地图标题。未识别的自定义名称不会强制替换；改名结束后，仍需检查的外文名称会记入游戏日志。
