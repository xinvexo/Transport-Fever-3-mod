# 预设地图中文名称

在豪华版等预设地图新开局时，使用中国城市、街道名称和汉字人物姓名。产业按原生首次取名规则确定名称：采用原生最近城市、资源命名模板及中文产业描述，并按原生方位和编号规则处理重名。同一产业的建设主体与所属站点组使用相同的完整名称。

只修改名称，不创建、拆除或重建产业，不改变地形、对象位置或生产状态。没有独立名称的产业、站点、车库子实体不强制写入名称。

安装方式见[项目说明](../README.md#安装)。使用简体中文界面，重启游戏后，在新开地图前启用“预设地图中文名称”，进入地图后让游戏运行片刻。

本版本不追改旧存档名称，也不继续旧版本未完成的改名队列；本版本新任务中断后可随读档继续。仅在开局或恢复本版本任务时处理，完成后停止扫描和改名，不做周期巡检。

适用于有城市的预设地图。没有城市、资源无法读取，或特殊站点重名进入尚不支持的随机附加词分支时，保留原名并记入日志。标准原生产业不使用该随机站点分支。独立于建设的自定义站点组名称保留原样。

城市名称是更换为中国地名，而非原地名音译。保留玩家昵称、公司名以及非默认的自定义线路、车辆名称，不修改地图选择菜单标题。在地图编辑器中不生效。继续游玩时保持模组启用，以维持后续的中文名称生成方式。
