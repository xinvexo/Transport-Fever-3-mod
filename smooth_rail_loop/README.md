# 铁路回环

在“铁路 → 铁路构造”中添加两种紧凑回环预制件。分岔口带间距 5 米的双线主轨短接轨段，前后各留一对接口，主线走向可自行延伸或弯曲。

| 预制件 | 形式 |
| --- | --- |
| 高架回环 | 中部相对放置高度抬升 16 米 |
| 地下回环 | 中部相对放置高度下沉 12 米 |

两种回环都会根据实际地形分段使用地面轨道、桥梁或隧道，同一回环可以混合桥隧；名称只表示回环的升降方向。

## 使用

安装方式见[项目说明](../README.md#安装)。

1. 启用模组，打开铁路建设菜单中的“铁路构造”图标。
2. 选择高架回环或地下回环，设置轨道类型、接触网及当前年代可用的原版铁路桥型。
3. 移动鼠标预览，通过菜单控件调整高度和旋转，单击放置；Esc 取消。放置后将前后四个接口接入主线。

两种回环的轨道中心线占地均约 140×211 米，主轨仅在分岔点前后各保留 25 米，不预铺圈内主线。回环半径 70 米，坡度约 8%；地形、桥墩和既有设施冲突以游戏施工检查为准。
