# 铁路回环

在“铁路 → 铁路构造”中添加两种回环预制件，两端为间距 5 米、同高的平行轨道接口。

| 预制件 | 形式 |
| --- | --- |
| 高架回环 | 中部抬升 8 米，使用石桥 |
| 地下回环 | 中部下沉 12 米，使用铁路隧道 |

## 使用

安装方式见[项目说明](../README.md#安装)。

1. 启用模组，打开铁路建设菜单中的“铁路构造”图标。
2. 选择高架回环或地下回环，设置轨道类型和接触网。
3. 用原版建造工具预览、旋转和整体升降，在空地放置后将两端接入主线。

轨道中心线占地约为：高架 260×406 米，地下 260×501 米。紧凑引道较陡，坡度约 7.8%；地形、桥墩和既有设施冲突以游戏施工检查为准。
