# 两点铁路回环 · 本地开发版 r3.2

入口位于原生铁路铺轨菜单左侧的模式栏：第三个回环图标。选择普通轨道类型后，在两条已有轨道上各点一个连接点。工具按连接点的位置和切向生成回环，鼠标沿轨道方向移动调整延伸长度，移到另一侧改变回环方向。

沿用原菜单的高度、弯曲、自动对齐、桥型、隧道类型和地下显示开关，没有额外的长度、高度或方向面板。新轨道采用当前菜单选中的轨型；原轨道切分后保持原有轨型、接触网和桥隧类型。

- 高度：回环中部相对连接点的升降；两端仍接回原高度。较大的升降需要更长的引道。正高度在达到桥梁阈值后使用所选桥型，负高度在达到隧道阈值后使用所选隧道类型。
- 弯曲：调整回环横向形状。过急曲线、过大坡度或引擎检测到碰撞时不允许施工。
- 鼠标：选两点后移动调整长度；预览通过检查后单击确认，右键重选。原高度和弯曲快捷键仍复用原菜单的步长。
- 地下开关：切换地下显示；降低高度决定回环是否进入地下。
- 回环模式使用高度曲线连接两端，所以暂时禁用固定坡度模式和追踪地形。

限制：中段连接点所在轨道段不能带信号或路标，工具会提示换段，避免丢失这些对象。已有端点不需要拆段，可保留对象。两点必须属于不同轨道段。车站锁定轨道、复杂道岔、桥隧净空、地形碰撞及模组轨型兼容性最终以引擎检查为准。

本次修正：

- 修复游戏 Lua 5.2 中 `math.atan(y,x)` 忽略第二参数、导致方向算错的问题。统一使用兼容的 `atan2`，修复选完两点就提示“这两个方向无法生成回环”的失败。
- 自定义动作直接创建原生 ActionDescriptor，移除引发 descriptorNodeId 断言的额外 recipe 包装。
- 从 Toolbar 参数 API 读取回环模式和高度、弯曲；不再从另一套 Default 参数缓存读取。
- Toolbar API 在轨型切换时共享，避免图标仍为回环但实际退回普通铺轨。
- 空白地面单击也能确认已验证的预览；未通过检查时不会建造。
- 增加模式切换、工具进入、选点和预览失败日志。

验证状态（2026-10-08）：用户实机日志已确认 r3.1 的原菜单回环模式和两次选点均进入成功，之后在模组几何求解中失败，尚未提交引擎检查。主测试现已明确采用与游戏一致的 Lua 5.2；修复后通过 240 组几何测试、6 种 Lua 运行时共 192 组旋转/平移/反向轨道测试，以及 Lua 5.2 下的菜单与施工方案集成测试。简单平行轨的测试回环累计转弯超过 180°，每个输出轨道段约不超过 11.1°。此前默认 Lua 5.5 的测试遗漏了旧版数学函数差异。**r3.2 的引擎预览与实际施工仍由用户继续验证。**

安装后请保存进度，回主菜单重新加载存档，再试原先的两个连接点，以便载入新脚本。启动日志将显示 revision 3.2。

## 开发

本目录是回环模组的开发源码。在仓库根目录运行 `python tools/test_mods.py smooth_rail_loop`，执行 Lua 5.2 几何、菜单/施工方案和跨版本方向角回归测试。依赖见根目录 `requirements-dev.txt`；测试不生成图片或报告文件。

按需在本目录运行 `python tools/package_mod.py`，输出本地 `dist/xin_smooth_rail_loop_1.zip`；附加 `--install /path/to/game/mods` 可安装到指定父目录。打包产物不入库、不上传。完整 Windows/macOS 开发方法见仓库根目录 README。
