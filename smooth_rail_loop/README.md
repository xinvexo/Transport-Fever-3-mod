# 两点铁路回环

在两条已有轨道之间生成平滑回环，按连接点的位置和方向自动调整形状，并可通过鼠标调整延伸长度。

安装方式见[项目说明](../README.md#安装)。目前为试用版，游戏内预览和实际施工仍待确认。

## 使用

1. 打开原生铁路铺轨菜单，选择轨道类型，点击左侧模式栏的第三个回环图标。
2. 在两条已有轨道上各选一个连接点。
3. 沿轨道方向移动鼠标调整长度，移到另一侧改变回环方向。
4. 预览通过检查后单击确认；右键重新选点。

沿用原菜单的设置：

- **高度**：抬升或降低回环中部，两端接回原轨道高度。升降达到相应条件后使用所选桥型或隧道；升降越大，需要的引道越长。
- **弯曲**：调整回环横向形状。
- **地下开关**：控制地下显示；降低高度决定回环是否进入地下。

## 使用限制

两点必须属于不同轨道段。在轨道中段选点时，该段不能带信号或路标；选择已有端点则可保留这些对象。

回环模式暂不支持固定坡度和追踪地形。过急曲线、过大坡度、车站锁定轨道及桥隧或地形碰撞，以游戏的施工检查为准。

更新模组后，请保存进度并回主菜单重新加载存档，以载入新脚本。
