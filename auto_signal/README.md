# 自适应铁路信号灯

放置一盏铁路信号灯后，从信号朝向前方的区段末端开始，按指定间距向后布灯。点击位置只触发布置，不影响生成的位置。

安装方式见[项目说明](../README.md#安装)。

## 使用

1. 启用模组，打开铁路信号灯建造工具。
2. 保持“自动布置”开启，设置“间距”：默认 300 米，滑块范围 50～800 米；点击数值可以输入其他正整数米，最小 1 米，也可以超过 800 米。
3. 选择信号灯类型和朝向，在目标区段放置一盏信号灯。

同向旧信号灯会被统一替换，新灯沿用本次放置的型号、朝向和单向属性；反向信号灯及其他轨道对象保留。关闭“自动布置”可恢复手动放置。

区段遇到铁路交点、结构所属轨道或轨道末端停止，普通轨道接缝不分段。第一盏灯放在前方末端之前 1 米，之后沿轨道每隔指定距离放一盏，剩余长度留在后端；短区段只放前端一盏，不重新均分或居中。

公路平交道口不把铁路区段断开。目标灯位落入道口禁放范围时，沿倒排方向顺延到可放位置，再从实际灯位继续计算间距；只在避让处增加必要的距离，不跳过整盏灯。桥隧跨越不按平交道口处理。

建造失败时保留原灯，不重试其他布局。没有端点的无分支环线需手动布置；一次超过 1000 盏时不执行。模组不识别进站、出站或线路用途，不调整单向设置。
