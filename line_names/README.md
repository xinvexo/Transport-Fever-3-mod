# 线路智能命名

在线路管理器的“自动重命名线路”中增加“城镇与产业·线路用途”方案。根据停靠地点和客货用途生成名称，区分同城与跨城线路，也支持工厂之间的货运和城镇到工厂的通勤客运。

例如：`北京 - 公交01`、`北京 - 天津 - 客运`、`大同 - 煤矿 - 北京 - 钢铁厂 · 煤炭01`、`北京 - 天津 - 食品厂 - 通勤`。名称各段用 ` - ` 分隔，只有末尾货物使用 ` · ` 分隔。货运按专线用途命名，跨城保留两端城市；同城只写一次城市名，例如 `北京 - 煤矿 - 钢铁厂 · 煤炭01`。可明确识别的重复城镇前缀会省略，自定义名称保留。

跨城客运通常一条专线配多辆车，默认不加编号；只有存在多条同名线路时才编号区分。增减车辆不会增加线路编号。同城公交和货运使用编号，同类线路的已有编号优先保留。多城线路保留沿途城镇信息。

原版道路车库、有轨电车车库、列车车库和船坞的默认名称也使用相同分隔符，例如 `三明 - 道路车库`。车库名称随启用模组后的资源加载生效，无需在线路改名面板操作；手动设置的名称保留。停用模组后，车库恢复原版默认名称格式。

安装方式见[项目说明](../README.md#安装)。启用“线路智能命名”后，在线路管理器选中一条或多条线路，打开“自动重命名线路”，查看新方案的预览并点击应用。原有命名方案仍可使用。

只修改本次选中的线路，包括选中的自定义名称；不会在后台持续改名。调整线路、配车或装载设置后，可再次使用此方案。已有且仍符合当前方案的编号优先保留，编号不保证连续。停用后保留已经应用的名称。

产业识别依据车站可达范围。一个站同时服务多个无法区分的产业，或同时服务产业与城镇时，保留站名；不会猜测主要目的地。货物优先参考装载设置与车辆能力，必要时参考当前载货；无法明确货种时使用“货运”。未配车、未确定站台或尚无有效装载设置的线路可能使用较概括的名称。

地名和产业名沿用存档，功能文字随游戏语言变化。中文示例以简体中文界面为准。名称沿用玩家设置的停靠顺序，货运请将供货站放在前面。多站线路只对明确的对称往返站序识别折返点，不推测货流方向、环线方向或快慢车等级。
