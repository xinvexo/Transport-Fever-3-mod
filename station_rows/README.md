# 车站整列配置

《狂热运输 3》mod，ID 为 `xin_station_rows_1`。

在原版模块化火车站的配置界面，选中轨道或站台模块，按住 Shift 点击原版可建槽位的小点，沿铁轨方向补齐这一列的空位。长度以车站现有轨道、站台的纵向范围为界，包含本次点击的位置。支持客运站和货运站。已有模块保持原样；轨道、客运站台和两格宽货运站台占用的位置会跳过。

使用配置界面的删除工具，按住 Shift 点击模块，删除同一列的同类模块。删除站台时同时移除其顶棚和附属模块。顶棚和附属模块只补在该列已有客运站台的空位。站房等非纵向模块仍按原版单点处理。

使用游戏的“精确模式”修饰键绑定，默认是 Shift。悬停使用原版单块预览、槽位小点和场景配色；按下 Shift 时记录当前车站；点击由原版完成第一块，收到引擎施工完成通知后才继续处理同列剩余模块。松开 Shift 按原版逐块操作。

剩余模块逐个提交原生建设命令。每一步成功后重新读取更新后的车站，再处理下一块；新增前检查当前位置是否仍为空，删除站台前先删除它的顶棚和附属模块。某一步被游戏拒绝时停止剩余操作。只处理这次操作对应的车站，不扫描全地图。

## 验证状态

整列增删流程已通过游戏内反馈确认。空位计算、Shift 输入、引擎施工通知衔接和串行命令使用 Lua 模拟测试验证。

## 打包与安装

运行 `python3 tools/package_mod.py` 生成 `dist/xin_station_rows_1.zip`。

运行 `python3 tools/package_mod.py --install "/path/to/game/mods"` 同时安装。

开发测试：安装 `requirements-dev.txt` 后运行 `python3 -m unittest discover -s tests -v`。
