# 车站整列配置

在原版模块化火车站中，按住 Shift 整列增删轨道、站台、顶棚和附属模块。支持客运站和货运站。

Mod ID：`xin_station_rows_1`。安装方式见[项目说明](../README.md#安装)。

## 使用

- **整列添加**：打开车站配置，选中模块，按住 Shift 点击可建槽位的小点。
- **整列删除**：选择删除工具，按住 Shift 点击模块，删除同列的同类模块。
- 松开 Shift 恢复原版逐块操作。若改过按键绑定，以游戏“精确模式”的修饰键为准。

添加范围以车站现有轨道、站台的纵向长度为界，包含本次点击的位置，并跳过已占用的槽位。顶棚和附属模块只补在已有客运站台上；删除站台时会一并删除其顶棚和附属模块。站房等非纵向模块仍按单点处理。

悬停时显示原版单块预览。整列施工逐块完成；某一步被游戏拒绝时，剩余操作停止。
