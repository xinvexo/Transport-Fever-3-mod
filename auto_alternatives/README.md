# 自动备用站台

为线路新添加的停靠站自动补选备用位置；车站扩建后，也会补选新增站台。候选站台须与主站台同属一个站点组，且运输方式和客货用途匹配。

安装方式见[项目说明](../README.md#安装)。

## 使用

1. 在存档中启用“自动备用站台”。
2. 在线路管理器中添加停靠站，匹配的备用位置会自动勾选。
3. 可随时手动调整备用位置或设为“不使用”；已有选择会保留。

适用于公交、货车、有轨电车、船舶、飞机和直升机的车站内站台。火车线路及路边停靠点不参与自动设置。

扩建只补选新增站台；延长原站台不会重新启用已停用的位置。切换首选时，符合条件的旧首选会补为备用。停用模组后，已写入的备用设置仍保留。

备用匹配不保证路网可达。出现无路径提示时，请检查连接或将该位置设为“不使用”。避免同时启用其他自动修改线路站台选择的模组。
