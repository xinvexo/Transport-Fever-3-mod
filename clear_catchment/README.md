# 清晰站点范围

建造车站、放置沿路停靠点或配置车站模块时，用较深的边界和半透明填充显示已有站点的服务范围。

- 同时显示已有客运站、货运站、公交站和沿路停靠点的范围。
- 沿用游戏原有的客货色调，把颜色调深，线条粗细保持不变。
- 圈内使用较明显的同色半透明填充，基础不透明度为 80%，方便辨认整个范围；重叠区域可能更深。
- 不额外改变房屋分区配色或添加光柱。退出站点建造后恢复原版显示。

安装方式见[项目说明](../README.md#安装)，安装后在存档模组列表中启用“清晰站点范围”。

只改变显示外观，不改变实际服务半径和覆盖规则。适用于原版站点及沿用原版站点建造界面的模组。

增强对象是已经建成的站点；正在放置的新站预览仍由游戏控制。这种显示方式可能比原版当前工具显示更多已有站点的范围。单独查看站点信息窗口时仍使用原版显示。

镜头拉近时，游戏仍会自动淡化范围圈，因此近景和远景的显示强度不同。

如果范围显示增强发生错误，本次加载会恢复原有显示；重新加载存档后再尝试。
